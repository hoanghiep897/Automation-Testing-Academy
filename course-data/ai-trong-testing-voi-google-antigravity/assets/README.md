# Assets

Thư mục này chứa 30 ảnh nguồn dùng trong bài học. JSON ghi URL gốc, đường dẫn ảnh cục bộ và SHA-256.

Video được đăng dưới dạng URL xem/nhúng và metadata trong `videos.json`; không có file MP4 hoặc thư mục `assets/videos/` trong bản repository theo yêu cầu chủ sở hữu. Các video tải về vẫn được giữ riêng trong bản xuất cục bộ.
